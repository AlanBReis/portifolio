Projetos

Automatizando a Extração de Dados da ANS com Apache Airflow

Imagine ter um assistente digital que vasculha a internet em busca de informações importantes, extrai dados de arquivos PDF e organiza tudo em planilhas fáceis de entender. Foi exatamente isso que eu construí com este projeto!

Utilizando o Apache Airflow, uma ferramenta de orquestração de fluxos de trabalho, desenvolvi um pipeline automatizado que coleta dados, transforma-os em arquivos CSV e os compacta para facilitar o armazenamento e o compartilhamento.

Este projeto demonstra como a automação pode simplificar tarefas complexas de extração e transformação de dados, economizando tempo e recursos.

Dashboard Interativa com Spotify e Power BI

Neste projeto utilizei Python, a API do Spotify e Docker para coletar e tratar dados de uma playlist de forma automatizada.

Os dados foram analisados e visualizados no Power BI com gráficos interativos, destacando informações como as músicas mais populares, duração total da playlist e quantidade de músicas.

A dashboard segue o estilo visual do Spotify, com cores escuras e detalhes vibrantes — ideal para demonstrar integração de APIs, automação com Docker e visualização de dados.

Lakehouse Analytics Pipeline com Delta Lake e Power BI

Neste projeto desenvolvi um pipeline completo baseado em arquitetura Lakehouse, utilizando PySpark, Delta Lake e Databricks para ingestão, tratamento e organização de dados.

Os dados são consumidos diretamente do Delta Lake e visualizados no Power BI por meio de dashboards interativos, com KPIs para análises estratégicas. O projeto demonstra arquitetura de dados, versionamento, otimizações com ZORDER e integração com ferramentas de BI.
