# Portfólio Engenharia de Dados - Alan Borges dos Reis

Bem-vindo ao meu portfólio! Aqui você encontrará uma visão geral dos meus projetos, habilidades e certificações na área de Engenharia de Dados.

## Sobre Mim

Olá, sou Alan, estudante de Engenharia de Software na Unicesumar com foco em Engenharia de Dados. Comecei minha trajetória na tecnologia em 2023 e, ao longo do tempo, fui migrando para a área de dados, onde desenvolvi habilidades em processamento, modelagem e análise de grandes volumes de informações. Tenho experiência na construção de pipelines de dados escaláveis, utilizando ferramentas de nuvem como AWS e Azure. Meu objetivo é criar soluções eficientes para coleta, transformação e armazenamento de dados, garantindo qualidade e performance.

## Habilidades

- **AWS e Azure**: Utilização de serviços de nuvem para armazenamento, processamento e análise de dados (S3, Glue, Redshift, Azure Data Factory, Synapse Analytics).
- **Banco de Dados**: Modelagem, otimização e consultas em bancos relacionais (PostgreSQL, MySQL) e NoSQL (MongoDB, DynamoDB).
- **ETL e Pipelines de Dados**: Construção de fluxos de ingestão e transformação de dados com Apache Airflow, DBT e Spark.
- **Big Data**: Processamento distribuído e análise de grandes volumes de dados com Hadoop e Spark.
- **Programação**: Desenvolvimento em Python e SQL para manipulação e processamento de dados.
- **Data Warehousing**: Estruturação de armazéns de dados para análises e BI.
- **Monitoramento e Qualidade de Dados**: Implementação de boas práticas para governança e confiabilidade dos dados.
- **CI/CD para Dados**: Integração e entrega contínua para pipelines de dados utilizando GitHub Actions e Terraform.
